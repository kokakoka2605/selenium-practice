# Тест-план: saucedemo.com

## 1. Цель
Проверить вход, корзину и отображение каталога на saucedemo.com и найти дефекты до начала использования

## 2. Объекты тестирования (in scope)
- Вход в систему 
- Корзина
- Каталог товаров

## 3. Вне рамок(out of scope)
- Оформление заказа(checkout)
- Нагрузочное и security-тестирование 

## 5. Подход и инструменты
Автоматизация: Java 24, Selenium, JUnit 5, Page Object, Allure, GitHub Actions. Ручная проверка: исследовательское тестирование пользователя problem_user.

## 4. Виды тестирования
Функциональное (UI), positive и negative, smoke, regression.

## 6 Окружение 
Chrome  157.0.8103.78 ,Windows 11,https://www.saucedemo.com/

## 7. Роли 
QA-инженер: ручное тестирование, автотесты, баг-репорты

## 8. Риски
- изменение сайта 
- другие локаторы 
- нестабильный интернет

## 9. Критерии начала 
Сайт доступен, тестовые аккаунты работают, окружение настроено

## 10. Критерии окончания
Все тест-кейсы выполнены, нет открытых багов High severity, открытые баги задокументированы

## 11. Артефакты
Чек-лист, тест-кейсы, баг-репорты, RTM.
